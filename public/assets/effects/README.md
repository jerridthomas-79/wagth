# WAGTH Effects Assets

Approved effect family for the WAGTH visual system.

## Green supernatural energy

Canonical production source: `green-supernatural-energy.png` (transparent PNG).

Used behind Judge reveals, winner moments, supernatural states, and other high-impact judgment moments. Green is reserved for Judge / supernatural energy in the established visual system.

The binary PNG is generated and ready for upload; this repository connector currently supports text/SVG commits but not local binary PNG upload.
